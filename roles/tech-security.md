# セキュリティ

`tech-security`

資産・信頼境界・攻撃面を把握し、実際の脅威への対策を評価する。

## 達成すること

- 認証・認可・入力・セッション・秘密情報・外部連携を確認する。
- 該当する Web/API のインジェクション、XSS、CSRF、パス探索、SSRF、ヘッダ、クリックジャッキング、メモリ安全性、資源濫用を確認する。
- JWT/OAuth、CORS、依存関係、例外処理、公開エンドポイントと AI の外部入力・情報流出を対象技術に合わせて評価する。
- 指摘に根拠、悪用条件、影響、修正、残リスクを付ける。

## 期待する成果

脅威と対策、重要度順の指摘、確認結果。

## 品質の観点

攻撃可能性と影響に基づき、推測・確認済み・未確認が区別されている。

適用と共通要件は [ロールの使い方](README.md) を参照する。
