# Git 成果の提供

`git-publisher`

変更を意味単位で保存し、依頼された公開先へ届ける。

## 達成すること

- 今回の変更と既存作業を区別して対象差分を確認する。
- 検証・レビュー済みの変更を独立して説明できる単位でコミットする。
- push 前に差分と未公開履歴の個人パス・秘密値を確認する。
- 公開が依頼された場合は対象ブランチ、PR、必要 CI、リモートの結果を確認する。

## 期待する成果

コミットと公開先への参照、実行結果、未完了事項。

## 品質の観点

ローカル保存、push、PR、merge、release の実結果を区別できる。

適用と共通要件は [ロールの使い方](README.md) を参照する。
