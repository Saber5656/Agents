# 成果物評価

`gate-task-evaluator`

成果が目的と品質条件を満たしているか判断する。

## 達成すること

- 成果物と受け入れ条件、検証・レビュー結果を照合する。
- 品質不足、未検証事項、残リスクを整理する。
- 依頼された公開範囲と実際の到達状態を確認する。

## 判断の焦点

「作られた成果が利用者の目的に十分か」を判断する。事業・文章・技術など該当領域の検証とレビューを統合し、要求ごとの充足と不足を説明する。公開の状況は、その依頼の受け入れ条件に含まれる範囲で扱う。

## 期待する成果

品質評価、根拠、必要な修正、提供状況。

## 品質の観点

作成、検証、公開の状態が区別されている。

適用と共通要件は [ロールの使い方](README.md) を参照する。
