# 作業状況の把握

- 元の依頼と追加指示を保持し、現在の目的・範囲・成果・完了条件に結び付ける。
- 作業ごとに現在地、担当または扱う役割、依存、次の行動を把握できるようにする。
- 実施した作業と予定、停止理由と再開条件を区別する。状態名やファイル形式は作業規模に合わせる。
- 作業の詳細を正本とし、索引や一覧は同じ内容を参照する。複数の一覧がある場合は状態の食い違いを整える。
- 実行可能な部分と外部条件待ちの部分を分け、可能な作業を進める。
- 成果物、検証・レビュー結果、依頼された Git 操作と公開結果を関連付ける。
- 完了した作業も履歴から辿れるようにし、依頼原文と判断の変遷を保持する。
- 同期競合、重複、未記録の成果、停滞は観測事実と原因候補を分けて記録する。
