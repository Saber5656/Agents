# 公式情報の確認と形式の受渡し

料金・プラン・利用条件・エクスポートは変わる。以下は入口であり、契約や実行の直前には
対象アカウントの条件と公式情報を再確認し、日付・URL・確認できた範囲を記録する。
提供元の「print-ready」は個別モデルの検査結果ではない。

| 一次資料 | 確認する内容 | 2026-09-21の取得状況 |
|---|---|---|
| [Tripo Maker](https://www.tripo3d.ai/maker-program) | 複数視点、部品分割、STL/3MF/OBJ、スライサー受渡し | 本文確認。プランごとの権利や実機成功とは別 |
| [Tripo料金](https://www.tripo3d.ai/pricing) | 料金、課金周期、credits、書出し制限、公開/非公開、商用条件 | 本文確認。Freeの非商用・公開モデルと有料プランの条件を区別。年/月表示が混在し、単月契約金額を固定しない |
| [Hi3D Create Task](https://docs.hi3d.ai/en/api/api-reference/list/create-task) | 入力画像、多視点入力、利用可能な出力・API条件 | 本文取得はtimeout。公式検索結果にmulti_imagesがあるが、プラン・料金・全出力形式は未確認 |
| [Blender 3D Print Toolbox](https://extensions.blender.org/add-ons/print3d-toolbox/) | 現行版の互換性と検査機能 | 直接取得はエラー、公式検索結果のみ確認。導入・機能実行は未確認 |
| [Blender displacement](https://docs.blender.org/manual/en/latest/render/materials/components/displacement.html) | 陰影だけのbumpと形状変位の差 | 検索経由の公式本文を確認。書出し結果は別途実データで確認 |
| [Prusa設計ガイド](https://help.prusa3d.com/article/modeling-with-3d-printing-in-mind_164135) | 支持、向き、薄肉、はめ合い、試作 | 本文確認。掲載の機種固有数値を別の実機の保証値に転用しない |
| [Prusa 3MF保存](https://help.prusa3d.com/article/saving-projects-as-3mf_1773) | 形状とスライサープロジェクトの違い | 本文確認。PrusaSlicerの設定保存説明を他ソフトの完全互換としない |

生成サービスを選ぶ際は、今回必要な入力（単一画像/整合した三面図）と出力、
ローカル修正への受渡し、実際のプランでの利用可否を比較する。両サービスの併用や契約を必須にしない。
公式本文を確認できなければ、検索断片だけで有料機能の提供や商用許可を確定しない。
サービスの商用利用条件は、入力キャラクター等の権利確認とは別問題として必要時に扱う。

| 形式 | 使いどころと確認 |
|---|---|
| GLB/OBJ/FBX等 | 生成原本・中間形式。テクスチャ/リグ/単位の受渡しは実ファイルとインポーターで確認 |
| .blend | 編集可能な状態。印刷用の複製と元の非破壊編集状態を区別 |
| CAD原本/STEP等 | 寸法拘束と部品設計の原本。対応スライサーへの受渡しは個別確認 |
| STL | 表面三角形による形状。画像テクスチャは保存されない。意図したmm寸法を別記して読込後照合 |
| 3MF | 色/テクスチャを格納できることと、そのソフト/プリンターで出力できることは別。色・部品・材料割当と設定を検証 |

形状用3MFとスライサーのプロジェクト3MFを区別して保存する。
他者のプロジェクト3MFを読むときは、機種・材料・カスタムG-code等の設定が
実機に適合するか確認してから使い、拡張子だけで互換と扱わない。
