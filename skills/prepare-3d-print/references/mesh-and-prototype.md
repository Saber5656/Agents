# メッシュ整形と試作の判断

## 原本から検査版へ

原本を複製して作業する。原本名/ハッシュ、編集版、ソフトの版、入力単位、完成寸法を記録する。
BlenderのScene Units、Object Scale、ワールド寸法とエクスポート設定を照合する。
STLには単位の明示情報がないため、mmでの意図寸法を記録し、スライサーへ再読込して確認する。
読み込めない・破損・スケール根拠不明の場合は修復成功とせず、失敗と必要な入力を残す。

## 外観と実形状

無地のSolid表示と必要に応じたワイヤーフレーム/断面、同じ角度の前後画像で比較する。
色、normal/bumpだけの陰影は立体形状ではない。必要な顔・模様は凹凸や独立パーツとして設計する。
レンダリング用displacementが書き出しメッシュに残るとは限らないため、
適用・実体化後に再インポートした印刷データで確かめる。
指の本数、左右、顔、シルエット、接触箇所を基準画像と照合する。
隠れた背面等の追加は推定設計として扱う。

## 検査と修正

利用中のBlender/3D Print Toolbox等の版で使える検査を確認し、
件数、対象部位、閾値、単位、前後結果を記録する。GUIのメニュー名を古い版から固定しない。

| 観点 | 判断と修正後の確認 |
|---|---|
| 穴・非多様体 | 境界や分岐を特定する。意図した空気穴・口・ダクトを塞がない。中空壁も材料として閉じた表面を作れる |
| 法線・重複・縮退面 | 内外・面の向きを確認。再計算後の薄い部位や内壁も見る |
| 自己交差・内部面 | 交差の検出方法と未検査箇所を明示。表面が閉じていても自己交差は別検査 |
| 浮遊部品・接合 | 独立した島を数え、意図した分割か未接合かを判定。見かけだけの接触は結合ではない |
| 肉厚・細部 | 完成寸法と材料/ノズル/線幅に対して評価。スクリーンショットやポリゴン数から厚さ合格を出さない |
| 分割・支持 | 造形サイズ、積層方向、接地、オーバーハング、サポートが内部から取り出せるかを確認 |
| CAD接続部 | 内外径、挿入長、肉厚、干渉範囲、固定方法を実測。公差は材料・向き・設定ごとの試験片で調整 |

Voxel Remesh、Make Manifold、Boolean、Decimate等は複製に適用する。
処理後に穴や表情が消えていないか、部位が増減していないか、寸法・容積が意図どおりか比較する。
検査ツールの自動修復完了表示は、必要なデザインの保持も造形成功も証明しない。
機械検査ができない項目は `NOT_RUN` とし、目視で代替できた範囲だけ記す。

## CADと装飾メッシュの接合

寸法を要する部分はパラメータと測定根拠を保存し、後から再生成できるようにする。
固定面やダクトを装飾メッシュに組み合わせる場合も、荷重・密閉・清掃・組付けを機能部で成立させる。
物理可動部には軸・ストッパー・必要な隙間・強度を設計する。ボーンはこれらの代替にならない。

## TPUの復元性試験

TPUの銘柄・硬度尺度・乾燥と供給経路を確認する。色が合っても必要な性能を満たすとは限らない。
単なる薄いレリーフの曲がりと、立体物が潰れて戻ることを区別する。
壁厚・中空形状・通気・接合を試作変数とし、まず一度に変える条件を絞る。
未確認条件に対して最終の壁厚・インフィル・温度・速度を断定しない。

試験では完成サイズ、押す向き、押込み量、保持時間、復元時間、残留変形、繰返し回数、
裂け・剥離・漏気の観測を記録する。目標は用途に合わせて設定し、測っていない力を数値化しない。
小型試験片だけでは完成サイズの座屈や復元を保証しない。
実機試作の許可や条件がなければ試作計画までとし、試作結果は `NOT_RUN` とする。
