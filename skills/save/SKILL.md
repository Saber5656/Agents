このスキルが、プロンプトアーカイブの保存先・frontmatter・命名規則・機密情報マスクの責務を持つ。ルートの startup instructions に同じ詳細を重複して書かないこと。

以下のルールに従って、保存対象範囲の対話をObsidianに保存してください:

1. 保存先のベースディレクトリ: `${PROMPT_ARCHIVE_ROOT}`
   - 実環境の Vault パスは `.env` や `*.local.md` などの ignored file で管理し、Git 管理しない
2. 日付ディレクトリを作成: `10_Prompt/YYYY/MM/DD/`（今日の日付を使用）
3. 保存対象範囲の内容を20文字程度の日本語で要約し、ファイル名にする（`.md` 拡張子）
   - ファイル名に使えない文字（`/`, `\`, `:`, `*`, `?`, `"`, `<`, `>`, `|`）は除去する
4. 現在のエージェントに対応する frontmatter を使う:

- Codex:
```markdown
---
created: YYYY-MM-DD
agent: codex
directory: (現在の作業ディレクトリ)
tags:
  - ai-prompt
  - codex
---

(対話内容をここに記載)
```

- Claude Code:
```markdown
---
created: YYYY-MM-DD
agent: claude-code
directory: (現在の作業ディレクトリ)
tags:
  - ai-prompt
  - claude
---

(対話内容をここに記載)
```

### 保存対象範囲（重要）

- **保存対象は `save` が実行された直前までのやり取りに限定する**。ユーザーが `/save`、`saveして`、`保存して` などでこのスキルを呼び出したターン自体と、その後の保存処理に関するエージェント応答は本文に含めない
- `save` 実行時のユーザー発言に追加メモやタグが含まれる場合、その発言を会話ログとしては保存せず、必要に応じて frontmatter の tags または本文の「追加メモ」にだけ反映する
- 保存処理中に発生したツール実行ログ、保存完了報告、保存先パス表示は、保存対象の本文に含めない
- ユーザーが明示的に保存範囲を指定した場合も、指定範囲の末尾が `save` 実行ターンを含むときは、`save` 実行直前までで切る

### 記録方針（重要）

- **集約ノートとして作成する**: 単なるQ&Aログではなく、会話全体から再利用可能な知識・判断・成果物・次アクションを統合した状態を目標にする
- **情報を削らず、構造化して圧縮する**: 重要な前提、決定、調査結果、コードやコマンド、成果物パス、未解決事項を落とさない。冗長な相づち、保存依頼そのもの、作業実況は省略する
- **発言の逐語転記を主目的にしない**: ユーザー発言やエージェント応答は、判断理由や重要な表現を残す必要がある場合だけ引用する
- **コードブロック・図・表・箇条書きは、成果物や再利用価値がある場合に保持する**。単なる途中説明は要点化する
- **複数ターンの会話は、時系列ログではなく意味単位で統合する**。背景、要件、実施内容、結論、残課題が後から読んで分かる構成にする

推奨する本文構成:

```markdown
# (会話全体を20〜40文字程度で表すタイトル)

## 概要
(この会話で扱った目的・背景・最終状態)

## 主要な要件・前提
- (ユーザーが求めたこと、制約、判断に効いた前提)

## 実施内容・成果
- (行った調査、作成・変更したもの、重要な成果物パス)

## 決定事項・再利用できる知識
- (今後も参照すべき判断、ルール、運用知識)

## 未解決事項・次アクション
- (残課題がなければ「なし」)

## 追加メモ
(save 実行時の $ARGUMENTS があれば記載。なければ省略可)
```

5. `$ARGUMENTS` があれば、tags に追加タグとして含めるか、本文に追加メモとして記載する
6. 保存完了後、ファイルパスを表示する

## 機密情報のマスク処理

保存するコンテンツに以下の情報が含まれる場合、必ずアスタリスク (`****`) で伏せること:

- **API トークン・シークレット**: `sk-****`, `ghp_****`, `xoxb-****` など
- **パスワード・認証情報**: パスワード文字列、Bearer トークン、Cookie 値
- **個人情報**: メールアドレス (`t****@example.com`)、電話番号、住所、クレジットカード番号
- **環境変数の値**: `.env` ファイルの内容や `export SECRET=` の値部分
- **SSH 鍵・証明書**: 秘密鍵の内容

マスクの原則: **キー名・変数名は残し、値のみをマスクする**。文脈の理解に支障が出ない範囲で最大限マスクする。
