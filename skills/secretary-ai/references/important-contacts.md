# 優先度高 送信者リスト

> Gmail の優先度付けで「高」と判定する送信者。ユーザーが手動でメンテする。

## 形式

- メールアドレスかドメインを1行ずつ
- `#` で始まる行はコメント
- ドメイン指定は `@example.com` 形式

## 高優先度（即対応）

```
# 上司・取引先
# boss@example.com
# @important-client.co.jp

# 家族
# family@example.com
```

## 中優先度（その日のうちに）

```
# 同僚・社内通知
# @yourcompany.com
```

## 低優先度（バッチ処理可）

```
# ニュースレター・通知
# noreply@*
# notifications@*
```

## 運用メモ

- 新しい送信者を追加する場合、メールアドレスではなくドメインで指定するとメンテが楽
- スキルは「高優先度」のリストにマッチしたら `[高]` ラベルを付ける
- リストが空の場合は、件名キーワード（「緊急」「URGENT」「至急」「期限」）と未読フラグだけで判定する
